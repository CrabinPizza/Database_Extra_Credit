# Viewing JSON and Mermaid output files

See Sections 5 and 6 of `RUN_GUIDE_ENGLISH.md` for detailed instructions.

- JSON: Open with VS Code, TextEdit, or Notepad. Validate: `python3 -m json.tool output_demo/design.json`.
- Mermaid `.mmd`: Open in text editor, copy source into https://mermaid.live/ to view/export E-R diagram.
- `design.json` and `relational_schema.json` are generated outputs. `examples/normalization_case.json` is a separate input format for 3NF tests.
